# Infinite Image Carousel for Elementor

A lightweight Elementor widget plugin for creating infinite vertical and horizontal image carousels with dynamic column support.

## Features

- Infinite vertical image carousel
- Infinite horizontal image carousel
- Dynamic column settings
- Elementor widget integration
- Responsive image layout
- Lightweight and clean code
- No unnecessary external dependencies
- Easy to customize from Elementor

## Requirements

- WordPress 5.8+
- Elementor installed and activated
- PHP 7.4+

## Installation

1. Download or clone this repository.
2. Upload the plugin folder to:

```bash
/wp-content/plugins/infinite-image-carousel-elementor/
